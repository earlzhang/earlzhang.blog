我曾经写过一篇名为[我为什么选择IX WebHosting的美国虚拟主机](http://www.earlzhang.net/us-hosting/139/)的帖子，介绍我现在使用的[IX Web Hosting](https://www.ixwebhosting.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang) 20GLinux虚拟主机。

有朋友也想购买虚拟主机，便问我这家的虚拟主机是否适合他们。对于大多数人，我的答案是肯定的。但是对于部分从来没有虚拟主机使用经验的用户，我却不建议他们选购[IX Web Hosting](https://www.ixwebhosting.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang) 的虚拟主机。这家服务商走的是价格至上路线，虽然产品性能强大，但是产品线简单，而且提供的附加功能也比较少，就易用性上稍有遗憾。所以，对于虚拟主机入门者，我一般推荐的是[HostGator](http://secure.hostgator.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)的虚拟主机。

![](http://www.hostgator.com/images/logo.gif)

[HostGator](http://secure.hostgator.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)的虚拟主机共有四款计划，具体资料见文末。不过就个人感觉，Hatchling这款虽然便宜但是限制太多，除非你是第一个月想试用一下它家的服务，否则绝不推荐。Baby这个计划是我个人最推崇的，性价比算是相当不错的了。至于Swamp，比Baby就多了一个匿名FTP、Chilisoft ASP再加一个私人SSL，每月费用就要贵5美元，近50%，除非你的确有特殊需求，否则性价比太低。至于Semi Dedicated这款，价格贵得接近独立主机的费用了，根本不适合作为一款虚拟主机来考虑。所以下面文章不加说明，都是以Baby计划来评价。

Baby这款计划有5G空间和75G的月流量，每月收费9.95美元，一次性支付多月并无折扣。相比[IX Web Hosting](https://www.ixwebhosting.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang) 我使用的那款20G空间和300G月流量，每月7.95美元的(1年缴费)Business Plus计划来，显然贵了不少。所以我文章一开始就说了，这家的虚拟主机主要是适合初学者，为了配置的便捷多支付一点费用还算值得，但对于高手而言，这多花的钱就有点冤枉了。

好了，下面就依次点评一下这款Baby计划的优缺点。

优点：

  1. cPanel的管理界面。cPanel是美国虚拟主机服务商最常见的管理界面，你熟悉了这家的界面，那么以后使用所有使用cPanel的服务商就不会有太大的学习障碍。这点对于入门者还是颇为重要的。下图是cPannel界面的示意图。  

  2. ![](http://static.flickr.com/122/294474178_3875efa250_o.jpg)

  3. Fantastico快速安装功能。在我看来，这是对虚拟主机入门者最有价值的功能。现在静态网页越来越少，如果你打算使用诸如Wordpress这样的热门程序，就必须懂得如何安装、配置，这对于许多可能连FTP、PHP、SQL为何物的读者而言，难度高了一些。有Fantastico，一切都简单了。只需要在菜单中选择一下，确定你要安装的程序，然后按照提示输入需要的内容，Fantastico就会自动帮你完成安装、配置以及相应的数据库建立管理工作，此后用户就直接可以使用。整个过程相当傻瓜化，如果你害怕自行安装程序，那么这个功能就相当贴心了。下面的贴图是Fantastico支持自动安装的程序，种类相当齐全，而且每一个类别下选择也很多，包括了绝大部分主流的程序，大致可以满足各方面的需求了。  

  4. ![](http://static.flickr.com/120/294472521_e82e79384d_o.jpg)

  5. 无限量Email帐户。这点比[IX Web Hosting](https://www.ixwebhosting.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang) 在Business Plus计划下只提供5000个来的划算。不过除非你需要配置的Email数量多的惊人，其实这点差别并不太大。[HostGator](http://secure.hostgator.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)和[IX Web Hosting](https://www.ixwebhosting.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)一样，Email帐户除了POP3协议外，也支持更高级的IMAP协议。不过功能上，[HostGator](http://secure.hostgator.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)还是具有两大优势。第一是丰富的Webmail选择，[HostGator](http://secure.hostgator.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)有Horde、Squirre和RoundCube三种选择，适合功能要求不同的用户，不似[IX Web Hosting](https://www.ixwebhosting.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)只有Horde一种选择。第二就是[HostGator](http://secure.hostgator.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)提供垃圾邮件过滤的功能，这倒是[IX Web Hosting](https://www.ixwebhosting.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)不提供的。  

  6. ![](http://static.flickr.com/102/294472755_60d7f97599_o.jpg)

  7. Cron功能。利用这个功能，你可以设定虚拟主机上的某些命令定时自动执行。笔者以前介绍过几款[自己架设的RSS阅读软件](http://www.earlzhang.net/us-hosting/163/)，这些软件相比Bloglines这样的服务，一个最大的缺点就是必须手动要求程序去更新Feed。利用Cron功能就可以要求程序定时自动更新了。这是一个非常有用的功能，可惜[IX Web Hosting](https://www.ixwebhosting.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)却并不提供。

  8. 无限主域名和二级域名支持。[IX Web Hosting](https://www.ixwebhosting.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)一个很大的缺点就是只支持有限主域名和二级域名，虽然数量在大多数情况下已经足够。不过如果你有特殊需要，是个架站狂，那么显然[HostGator](http://secure.hostgator.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)在这点上有特别的优势。

  9. 无限SQL数。虽然[IX Web Hosting](https://www.ixwebhosting.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)的50个MySQL数对我已经很够用了，不过无限SQL总是好的。

  10. 强大的日志分析功能。虽然现在有不少提供访问统计的网站，包括google也有类似服务提供。不过最佳的访问统计，还是基于虚拟主机访问日志的。把日志变成我们可以阅读的分析报告，有赖于专门的程序。[IX Web Hosting](https://www.ixwebhosting.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)比较简单，只提供了Webalizer和Modlogan这两个最简单的日志分析程序。[HostGator](http://secure.hostgator.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)就不同了，有analog、awstats、urchin、webalizer四款提供。urchin就是被Google收购的那款，而awstats则是目前虚拟主机最常用的日志分析。不仅选择多，[HostGator](http://secure.hostgator.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)还提供awstats的实时更新分析报告，而不似[IX Web Hosting](https://www.ixwebhosting.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)仅每天更新一次日志分析报告，相当偷懒。如果你希望随时了解最新的访问动态，那么[HostGator](http://secure.hostgator.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)的这个功能就相当适合你了。

  11. Chilisoft ASP。这个功能Baby计划不提供，是Swamp的独门武器，也是在我看来Swamp昂贵的最重要理由。国内使用ASP程序的不少，不似美国一般是PHP一统天下。对于那些曾经使用ASP程序，目前逐步转向Linux下PHP的用户而言，必须放弃原有的ASP程序是相当痛苦的事情。比如笔者最早的Blog是用ASP的L-blog系统，虽然买了[IX Web Hosting](https://www.ixwebhosting.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)的Linux虚拟主机，但为了保证原有的L-blog系统仍能运行，所以之前订购的Windows主机也不能退订。但如果你选购了Swamp计划，那么就无需为此担心了，因为有了Chilisoft ASP，你可以在Linux主机上执行原有的ASP程序。

缺点：

  1. 不提供独立IP。这点对于我而言是致命伤。我实在不喜欢共享IP的不安定感。万一同一个IP上有什么违反政策的内容，你的内容就会受到牵连。如果你不像我这样对此问题那么敏感，那就无所谓了。似乎[HostGator](http://secure.hostgator.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)也提供独立IP另行选购，2美元/月，不便宜啊。

  2. 价格比较贵。这个一开始就说了，其实和许多同行相比，[HostGator](http://secure.hostgator.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)并不算贵，只不过一开始就习惯了低价位的[IX Web Hosting](https://www.ixwebhosting.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)，就会有贵的感觉。

  3. 不提供搜索引擎提交功能，必须自己提交或者另行选购其他的服务商，这点比较麻烦。

上述就是个人的一个简单评价，如果想到什么新的内容，再另行补充。

此外，[HostGator](http://secure.hostgator.com/cgi-bin/affiliates/clickthru.cgi?id=earlzhang)也提供独立主机和主机分销业务，有兴趣的读者不妨也看看。
