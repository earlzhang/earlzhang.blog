无聊之余，查了一下自己几个Blog的Google PR值。

其他几个老的Blog没有什么大的变化。但是这个从六月底才刚刚开始搭建的新Blog，Google PR值却让我目瞪口呆。

URL| PageRank| PageRank Bar  
---|---|---  

http://www.earlzhang.com/ | 2 |  |  |  |   
---|---  

http://www.earlzhang.com/lblog/default.asp | 4 |  |  |  |   
---|---  

http://www.earlzhang.net/ | 4 |  |  |  |   
---|---  

http://indexing.spaces.msn.com/ | 0 |  |  |  |   
---|---  

http://www.donews.net/earlzhang | 2 |  |  |  |   
---|---  

PR=4？！Blog.earlzhang.com的PR值竟然和我耕耘了两年的[www.earlzhang.com/lblog/default.asp](http://www.earlzhang.com/lblog/default.asp) 一样，这个也太让人吃惊了吧？

据说一个注册时间比较长的域名PR值会高一些，据说独立IP的PR值会高一些，据说架构良好的网站PR值会高一些。

虽然earlzhang.com这个域名也有两年多寿命了，虽然blog.earlzhang.com也使用了独立IP，虽然它用的Wordpress的确设计很不错。

但是，我还是现在这个Blog那么快有资格获得如此高的PR。毕竟，用site:blog.earlzhang.com在Google上搜索，虽然收录的页面每天在增加，但是迄今也不过63个啊。

突然响起，blog.earlzhang.com在正式用wordpress搭建这个Blog之前，一直使用域名转向功能指向[www.earlzhang.com/lblog/default.asp](http://www.earlzhang.com/lblog/default.asp)这个地址的，莫非就是因为这个原因，所以早在blog.earlzhang.com被用来搭建这个Blog之前就已经有了4的PR值？

我不懂搜索引擎优化，所以对此问题不甚了解，还请高手指点。如果的确是这样的话，那是不是过段时间Google会根据blog.earlzhang.com的新的内容而重新调整它的PR值呢？
