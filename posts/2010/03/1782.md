虽然做了Firefox很多年的粉丝，不过自打Google推出Chrome后，就逐步投奔他家阵营了。

毕竟，原生的书签同步、更快的浏览速度、对Gmail更好的支持，这些都是我所渴求的。不过，Chrome一直让我不满意的便是Tab管理，不能地址栏直接打开新Tab，不能书签直接打开新Tab，不能双击关闭Tab，习惯了早年的Maxthon，后来Firefox上又用插件实现了类似功能，实在不愿意改用鼠标中间来替代——尤其是我单位的罗技木星轨迹球压根就没有中键的前提下。找了半天Chrome的插件，没有支持类似功能的。

终于，有国人完善了这个Chrome困扰我许久的缺陷——虽然不是通过插件方式，而是在Chrome的基础上推出了一个衍生版本[ChromePlus](http://www.chromeplus.org/)。

这个ChromePlus既有Windows版本也有Linux版本，对于我这样跨平台的用户也毫无使用困难。至于功能，下面是最新的更新日志，可以看到虽然都只是一些小的细节改进，但却可以极大的改变使用体验，赞！

> * 鼠标手势。
> 
> * 超级拖拽。
> 
> * 广告过滤。支持AdblockPlus的广告过滤规则，并且部分隐藏规则匹配的内容也可以在加载前过滤掉。
> 
> * 便携版。
> 
> * 双击标签关闭页面。
> 
> * 新增选项：当最后一个标签关闭时的动作。
> 
> * 新增用户私密选项。
> 
> * 增加了地址栏打开模式（前台、后台及当前页打开）的选项。
> 
> * 增加了书签打开模式（前台、后台及当前页打开）的选项。
> 
> * 增加了下载右键菜单项“复制下载地址”。
> 
> * 可选的自动升级。
> 
> * 增加平滑滚动。
> 
> * 进程模式选择（单进程，多进程，混合模式）。
> 
> * 启动选项：匿名模式，禁用扩展，禁用插件，禁用java，禁用javascript，显示书签按钮，自定义cache目录，代理配置。
