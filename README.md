# 理性谈风月 Blog Archive

《理性谈风月》是我(张翼轸)的blog，依稀记得是始于2003年秋冬的某一天。最初是以L-blog架构寄居在好友王晨昀的主机之下。后来才自己买了服务器，并改以WordPress搭建。断断续续更新到2014年。

这个Blog，最早叫“张翼轸的虫二”，“虫二”取的是“风月无边”的含义。后来则改名为“理性谈风月”。

或许，这应该算是我的第一段网络Kol的生涯，聚焦的是男装、护肤、影视等乱七八糟的东西，还结集出版了一本《品味·男》。期间还遭遇了earlzhang.com域名忘记续费被抢注,被迫改用earlzhang.net而元气大伤的悲痛。

再之后，就专心写起了微信公众号EarlETF，开始了基金自媒体的另一段生涯。《理性谈风月》这个blog，也因为年久失修，后来无法访问了，在之后我更是将其在阿里云上制作成快照和镜像，将服务器下线了。

不过，后来时不时还有老读者来问，哪里可以看到旧文。正好AI编程时代来临，在几个大模型的辅导之下，重新启动当年镜像的实例，下载mysql文件，写了python分拆解析出一篇篇文件，制作索引，然后就有了这个github库。

以下，就是blog文章的存档，按年月整理，降序排列，共计 **1078** 篇文章。 因为主要都是文字作品，所以当年blog本地的图片并未恢复，好在本来就是文字为主的小文，少两张图片并不妨碍。
